# $160k Calculator vs TurboTax Comparison

Compare **the-long-math** Canada income tax calculator to TurboTax for **$160,000** in each income type, for every province and territory (2025).

## 1. Generate our calculator’s results

From the **repo root**:

```bash
node tools/tests/run-160k-comparison.js --year=2025 --out=our-results.2025.160k.json
```

This writes `tools/tests/our-results.2025.160k.json` and prints a table: **Province × Income type** with Total tax, Federal, Provincial, Taxable income, Marginal %.

Income types: **Salary**, **Capital gains**, **Eligible dividends**, **Other income**.

## 2. Fill TurboTax baseline

1. In TurboTax, set **year 2025** and **$160,000** in exactly one of: Employment income, Capital gains, Eligible dividends, Other income (all others $0).
2. For each **province/territory** and each **income type**, record:
   - **Total tax**
   - **Federal tax**
   - **Provincial tax**
3. Put them in `tools/tests/turbotax-baseline.2025.160k.json` with the **same row structure** as `our-results.2025.160k.json`: each row must have `province`, `incomeType`, `totalTax`, `federalTax`, `provTax`.

Easiest: copy `our-results.2025.160k.json` to `turbotax-baseline.2025.160k.json`, then replace the tax numbers with TurboTax values (keep `province` and `incomeType` so rows match).

## 3. Run the comparison

From the **repo root**:

```bash
node tools/tests/compare-with-turbotax.js
```

The script reports rows where the difference (ours − TurboTax) exceeds **$5** for total tax, federal, or provincial tax, and exits with code 1 if any such differences exist.

## Files

| File | Purpose |
|------|--------|
| `run-160k-comparison.js` | Runs our calculator for all provinces × 4 income types at $160k; writes JSON and table. |
| `our-results.2025.160k.json` | Our results (generated by step 1). |
| `turbotax-baseline.2025.160k.json` | TurboTax results; you fill this (step 2). |
| `compare-with-turbotax.js` | Diffs our results vs baseline and lists errors (step 3). |

## Provinces / territories included

AB, BC, MB, NB, NL, NS, NT, NU, ON, PE, QC, SK, YT.

**Note:** Quebec (QC) may differ from TurboTax if TurboTax uses Revenu Québec–specific rules not yet in our engine.
