Ce calculateur résout le rendement annuel nominal requis pour atteindre un objectif en dollars d'aujourd'hui.

La simulation directe et le solveur sont dans /assets/js/investment-growth.engine.js (InvestmentGrowthEngine).

Équations principales

rréel,annuel = (1 + rnom) / (1 + π) − 1

Cotisations indexées à l'inflation : cotisation réelle constante C ; cotisation nominale croît avec π.

Solveur : recherche binaire sur rnom jusqu'à RealFinal ≥ T.
