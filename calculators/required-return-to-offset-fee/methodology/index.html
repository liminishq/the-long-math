Inspect the Arithmetic — Required Return to Offset Investment and Management Fees

Version 2.0
Last updated: April 2026

Transparent arithmetic is the operating system of this calculator.

This document publishes the formulae, computational structure, and assumptions used to generate the outputs displayed on the calculator page.

No opinions. No hidden assumptions. Just arithmetic.

Purpose

This calculator answers two related questions using the same standardized-period portfolio simulation as the other fee tools:

  • What additional gross annual return (over your baseline) is required so that the with-fee path ends at the same value as the no-fee path?
  • If that extra return is not earned, how much additional annual contribution (reported in dollars per year) is required to match the no-fee ending value?

The rough mental shortcut “alpha equals the fee percentage” is not used. Required return and extra contribution are found by numerical search on the shared engine.

Definitions

Let:

  • P = starting balance (CAD)
  • Cannual = annual contribution entered on the page; internally split into 12 equal monthly amounts at standardized month start
  • t = horizon in years (converted to 12t monthly steps)
  • r = baseline gross annual return (decimal)
  • f = annual fee rate (decimal); fee modeled as monthly AUM deduction f/12 × balance after growth within each month
  • Endingno fee = result of the simulation with no fee
  • Endingwith fee = result at baseline r with fee f
  • α = required extra gross return (decimal) solved such that there exists r′ with Ending(r′, fee f) ≥ Endingno fee (reported as r′ − r)

Numerical solution

Required gross return: binary search on annual gross return r′ for the with-fee simulation until ending value meets or exceeds Endingno fee (solveAnnualReturnForEndingValue in /assets/js/engines/portfolioSimulationEngine.js).

Extra contribution: binary search on additional monthly contribution added on top of the baseline monthly amount for the with-fee path at baseline r, then multiplied by 12 for display as “per year” (solveExtraContributionPerPeriodForEnding).

Implementation Notes

  • Page script: /assets/js/required-return-calculator.js (loads after portfolioSimulationEngine.js).
  • Updated calculation method: older versions used closed-form annual math and the identity α = f; results may differ from those versions.
  • Display formatting rounds dollars to whole CAD; internal math uses full precision.

If any discrepancy is identified between this documentation and the live calculator output, portfolioSimulationEngine.js and required-return-calculator.js are the source of truth.
