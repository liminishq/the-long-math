Inspect the Arithmetic — Cost of a 0.5% Annual Fee

Version 2.0
Last updated: April 2026

Transparent arithmetic is the operating system of this calculator.

This document publishes the formulae, computational structure, and assumptions used to generate the outputs displayed on the calculator page.

No opinions. No hidden assumptions. Just arithmetic.

Purpose

This calculator compares the ending value with no fee versus the ending value with a 0.5% annual AUM-style fee, using the same standardized-period simulation engine as the advisor fee calculator and other fee-impact tools. It does not use the rough shortcut “net return = gross return − fee.” Fees are modeled as recurring deductions from the portfolio balance.

Definitions

Let:

  • P = starting balance (initial principal, CAD)
  • Cannual = annual contribution entered on the page (CAD)
  • Cmonth = Cannual / 12, deposited at the start of each standardized month (12 periods per year)
  • t = investment horizon in years
  • r = gross annual return (decimal), before fees
  • f = 0.005 for the default 0.5% annual fee (decimal)
  • Simulation uses standardized periods only (no calendar dates): monthly = 12 periods per year.

Model (summary)

Each standardized month: apply start-of-month contribution (if any), apply gross growth (1 + r)1/12 − 1 on the balance, then deduct the fee as f/12 × balance after growth. The no-fee path uses the same contribution and growth steps with no fee deduction.

Outputs

ΔFV = Endingno fee − Endingwith fee
PctReduction = ΔFV / Endingno fee

Implementation Notes

  • Engine: simulatePortfolioScenario() in /assets/js/engines/portfolioSimulationEngine.js, invoked from initFeeCostPage() in /assets/js/fee-ui.js.
  • Updated calculation method: older versions used a closed-form annual formula; results may differ slightly from those versions.
  • Display rounding uses whole dollars for ending values; internal calculations use full floating-point precision.

If any discrepancy is identified between this documentation and the live calculator output, the implementation in portfolioSimulationEngine.js and fee-ui.js is the source of truth.
