Inspect the Arithmetic — Active vs Passive Break-Even

Version 2.0
Last updated: April 2026

Transparent arithmetic is the operating system of this calculator.

This document publishes the formulae, computational structure, and assumptions used to generate the outputs displayed on the calculator page.

No opinions. No hidden assumptions. Just arithmetic.

Purpose

This calculator compares passive and active paths using the shared standardized-period simulation engine (monthly steps; fees as AUM deductions). It reports:

  • the break-even active gross return such that the active path (with active fee) ends at the same value as the passive path (with passive fee), solved numerically;
  • the implied excess return αbreak = ractive,break − rpassive (not the shortcut “feeactive − feepassive” unless they coincide numerically);
  • ending values for passive and active under the user’s assumed active gross return, and the active ending value at the break-even gross return.

Definitions

Let:

  • P = starting balance (CAD)
  • Cannual = annual contribution entered on the page; split into 12 monthly flows at standardized month start
  • t = horizon in years
  • rpassive, ractive = gross returns before fees
  • fpassive, factive = annual fee rates; applied monthly as AUM deductions after growth within each month

Numerical break-even

Let Endingpassive be the passive simulation at (rpassive, fpassive). The break-even active gross return ractive,break solves Ending(ractive,break, factive) = Endingpassive via binary search (solveAnnualReturnForEndingValue).

Implementation Notes

  • Engine: /assets/js/engines/portfolioSimulationEngine.js; UI: initActiveVsPassivePage() in /assets/js/fee-ui.js.
  • Updated calculation method: older versions used “net = gross − fee” closed-form FV; results may differ slightly.

If any discrepancy is identified between this documentation and the live calculator output, portfolioSimulationEngine.js and fee-ui.js are the source of truth.
