Inspect the Arithmetic — Investment Return Required to Reach a Goal

Version 1.0
Last verified: June 2026

Transparent arithmetic is the operating system of this calculator.

This document publishes the formulae, computational structure, and assumptions used to generate the outputs displayed on the calculator page.

No opinions. No hidden assumptions. Just arithmetic.

Purpose

This calculator solves for the annual investment return required to reach a stated portfolio target in today's dollars (real purchasing power). Inputs: starting balance, target balance (real), recurring contributions (real, inflation-indexed in nominal terms), time horizon, and assumed inflation. Outputs: required nominal and real annual returns, nominal equivalent of the target, breakdown, and accumulation schedule at the solved return.

It is an educational tool only. It does not model taxes, fees, contribution limits, or account rules.

Shared engine

Forward simulation and the return solver live in /assets/js/investment-growth.engine.js as InvestmentGrowthEngine.simulateInvestment() and InvestmentGrowthEngine.solveRequiredNominalReturn(). The Inflation-Adjusted Investment Calculator uses the same forward simulation.

Definitions

  • S = starting amount (today's dollars)
  • T = target ending balance (today's dollars)
  • C = contribution per period, entered in today's dollars
  • Y = time horizon in years (1–60)
  • π = assumed annual inflation rate (decimal)
  • rnom = required nominal annual return (unknown, solved)
  • rreal,annual = real annual return derived from rnom and π
  • m = contribution periods per year (12 or 1)
  • Bt = real balance at end of period t

Core equations

1. Real return

rreal,annual = (1 + rnom) / (1 + π) − 1

2. Inflation-indexed contributions

Contributions are entered in today's dollars. With inflation indexing (default), the real contribution each period stays constant at C. The corresponding nominal contribution in period t rises as C × (1 + π)t/m.

3. Forward simulation (real dollars)

For each period, apply contribution (beginning or end of period), then growth at rreal,period derived from rreal,annual and m. RealFinal = BT after m × Y periods.

4. Solve for rnom

Find the smallest rnom ≥ 0 such that RealFinal ≥ T (within $0.01 tolerance). Binary search on rnom. If RealFinal < T even at rnom = 1000%, the calculator still reports 1000% and shows a shortfall warning.

5. Nominal target equivalent

NominalTarget = T × (1 + π)Y

Historical context warning

When required rnom > 7%, the UI shows a contextual note: S&P 500 annualized total return (with dividends reinvested) over calendar years 1975–2024 was approximately 12.1%. This is historical context only — not a forecast or recommendation.

Implementation

  • Engine: /assets/js/investment-growth.engine.js
  • UI: /calculators/investment-return-to-reach-goal/ui.js
  • Shareable URLs encode inputs as query parameters (sa, tg, ca, th, inf, cf, ct).

If any discrepancy is identified between this documentation and the live calculator, the JavaScript engine is the source of truth.
